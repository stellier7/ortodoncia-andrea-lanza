# Financing images

Upload **two photos** for the Financiamiento section, then update `js/config.js`:

| File to upload | Config key |
| --- | --- |
| `financing-01.jpg` | `financingImages[0].src` |
| `financing-02.jpg` | `financingImages[1].src` |

Recommended: landscape JPG or PNG, at least **1200×800 px**.

**Upload on GitHub:**  
https://github.com/stellier7/dentist-template/upload/main/assets/images/financing

After uploading, change the `.src` paths in `config.js` from `.svg` to `.jpg` (or keep `.svg` if you upload SVGs).
